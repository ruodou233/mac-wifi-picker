# Mac WiFi Picker 验收清单

## 自动化检查

```sh
./Scripts/test.sh
./Scripts/build.sh
./Scripts/test-static.sh
```

模型测试覆盖：

- raw RSSI dBm 严格降序；
- RSSI 相同的稳定 tie-break；
- 同 SSID 多 AP 聚合并保留 2.4/5/6 GHz 明细；
- 重复 AP 观测只保留当前最强 RSSI；
- 相同显示名但不同安全类型不合并；
- 相同显示字符串但 SSID 原始 bytes 不同也不合并；
- BSSID 缺失时身份仍稳定；
- 隐藏/名称不可用结果不生成假行；
- 隐藏个人网络空密码返回“需要密码”，开放网络不会因误填密码而消失；
- SSID bytes 十六进制无损往返。
- 连接确认核对目标 SSID bytes 与安全类型，不要求 BSSID 或互联网路径；
- 同 SSID 但安全类型不同不能通过连接确认；
- 普通或隐藏网络的 CoreWLAN 关联超时后，若目标链路在总 deadline 内稳定出现，仍按成功收口；
- 首次断网显示、手动关闭抑制、手动显示优先级、已连接后台隐藏和真实断线 1.5 秒去抖策略。
- 连接成功后 1 秒内只发出一次隐藏请求；成功后的瞬时断线观察不能取消关闭任务；已关联复查不能重新打开。
- 链路观察超时不冒充真实断网；停止后排队回调不会重新显示；权限撤销后晚到扫描不能覆盖权限页。
- 选发射点：5/6 GHz 不低于 −70 dBm 优先、边界值、低于门限回到最强；列表排序和信号格不受影响。
- OWE 按开放网络分类；个人网络同时回答 OWE 时仍算个人；WEP 仍不支持。
- `DIRECT-` 热点过滤，当前网络和 `DIRECTOR` 这类名字不受影响。
- 信号档位（可见网络至少一格）、读屏标签、菜单栏图标状态、单击动作的判定；错误文字不带错误码。
- 行内加入：被点的行转圈，其他行不能点，失败原因写在该行下方；密码错误留在密码页；企业网和 WEP 点击打开设置；权限按钮按授权状态显示；面板关闭后晚到的失败不留在下次打开的页面上。
- 已保存网络：第一次不传密码且只试一次；失败进密码页、不写原因、不关面板；输入密码后第二次带密码；输入的密码失败时报错，不再回到空密码。
- 缓存结果先显示再被扫描替换；启动和唤醒宽限；操作过的面板不自动收起；失去焦点后暂停扫描；Wi‑Fi 关闭是单独状态；扫描失败不再停在“正在扫描”。
- 扫描进行中加入：模拟服务和真实服务一样扫描期间占着接口、取消不提前结束，加入要等扫描返回而不是报忙；交互后再经过一次断网检查，系统连上也不收起；WEP 和企业网都打开设置。

静态检查覆盖：

- 脚本语法、plist 合法、LaunchAgent 只在崩溃时拉起；
- 全应用只构造一个 `NSPopover`，且不创建 `NSAlert`、`NSWindow` 或 `NSPanel`，不管理 Apple 的 Wi‑Fi Agent；
- App bundle 的可执行文件、图标、版本号（和 `Resources` 里的一致）与代码签名可验证。

## 实机验收前置条件

1. 系统“定位服务”总开关已打开；
2. “Mac WiFi Picker”获准使用定位服务；
3. App 安装在 `/Applications`；
4. ad-hoc 签名，每次重新构建安装后要重新授权定位；
5. 自定义菜单栏 Wi‑Fi 状态项可见。

下文“看日志”指：

```sh
/usr/bin/log show --last 10m --predicate 'subsystem == "io.github.ruodou233.MacWiFiPicker"' --style compact
```

## 必做实机场景

| 场景 | 期望结果 |
|---|---|
| 定位关闭/拒绝 | 不显示假 SSID；一行“允许定位以显示网络名称”和“允许定位”或“打开定位设置…”按钮 |
| 首次授权 | 授权框出现在最前；授权后几秒内自动扫描并显示真实 SSID，不用重启 |
| RSSI 排序 | 连续刷新 10 次，信号格从上到下不增加；同值顺序不抖 |
| 同名 SSID | 主行取最强 AP，按它排序 |
| BSSID 为 nil | 仍可显示、排序和连接，不把 BSSID 当硬门 |
| 新个人网络 | 单击行进入同面板密码页；正确密码成功；错误密码留在这页，框下写“密码不正确”，已输入的密码全选 |
| 连接超时 | 端到端不超过约 30 秒；该行下方写“加入超时”；之后真的连上了，当前网络和菜单栏图标自己变；不叠加第二个 CoreWLAN 操作 |
| 已保存网络（实验性） | 单击后先用空密码加入。通过：能连上，且不弹钥匙串授权框；日志依次出现 `connect: <名字>, no password` 和 `connect: joined <名字>`。失败时进密码页，不写原因，错误码看日志里的 `connect: failed, …` 行：`operationInProgress` 或 `networkNoLongerVisible` 不算失败，重试一次；凭据错误或弹了钥匙串框算不通过 |
| 企业网络和 WEP | 不出现普通密码流程；点一下打开系统 Wi‑Fi 设置，面板收起，日志里没有新的 `connect:` 行 |
| 隐藏网络 | 输入准确 SSID 后定向扫描；找不到时明确报错 |
| Captive Portal/无互联网 | Wi‑Fi 关联成功即隐藏，不把互联网可达当硬条件 |
| 连接成功 | 目标 SSID bytes 连续稳定后面板收起，进程仍在，没有成功提示 |
| 真实断线/Wi‑Fi 关闭 | 真实断线去抖后面板出现；Wi‑Fi 关闭不自动弹出，手动打开时显示“打开 Wi‑Fi” |
| 自动弹出时 | 正在别的 App 打字不丢焦点；回车不加入；鼠标第一下点网络就连接；热点回来后被点过的面板不收起 |
| 双频网络 | 单击后落在 5/6 GHz（`system_profiler SPAirPortDataType` 核对） |
| 菜单栏图标 | 随信号变化且至少一格；未连接空扇形；关闭斜杠；缺定位权限时照常显示信号格、不出感叹号；没有悬停提示 |
| 面板外观 | 没有箭头，顶部贴近菜单栏；液态玻璃上次要文字和锁看得清（深色、浅色壁纸各一次）；只有被截断的名字悬停才出全名 |
| 键盘和 Esc | 手动打开等 15 秒以上（期间会刷新），↓ 仍能移动选中，回车作用于选中的那一行；密码页第一次 Esc 回列表，第二次关闭面板；密码页的“加入”是蓝色默认按钮 |
| 暂停扫描后点击 | 打开面板，点别的 App，等 70 秒以上；约 60 秒后日志出现 `scan: paused after 60s without focus`；之后直接点一个网络，出现新的 `scan:` 行，加入成功，不出现“Wi‑Fi正忙” |
| 右键图标退出 | 退出后不被 LaunchAgent 拉起；下次登录或 `launchctl kickstart gui/$(id -u)/io.github.ruodou233.MacWiFiPicker` 恢复（`install.sh` 安装时） |
| VPN/有线断开 | 只要 Wi‑Fi 仍关联就不误弹 |
| 用户手动关窗 | 30 秒内不抢焦点，之后断网入口恢复 |
| 重启登录 | 登录启动后在后台运行；已联网时不弹窗，未联网时显示 |
| 睡眠唤醒 | 不重复开窗、不崩溃，链路稳定后状态正确 |

断网自动弹出可以这样测：连手机热点，并在系统设置里临时关掉其他已知网络的“自动加入”（测完恢复）；在备忘录里打字时关掉热点，面板弹出后继续打字并按回车，再用鼠标点一个网络。

自定义菜单栏入口和加入流程验收通过后，可以隐藏 Apple 的菜单栏 Wi‑Fi 项；系统设置本身仍由 macOS 保留。
